# Zime

円の色の面積で経過時間がわかる、macOS用のビジュアルタイマーです。

## 開発を始める

GitHub直下の **Zimeフォルダ** がリポジトリのルートです。CodexやVS Codeでは、このフォルダを選択してください。

1. 直下の `Zime.xcodeproj` をXcodeで開きます。
2. Schemeを **Zime**、実行先を **My Mac** にします。
3. **⌘R** で起動します。追加パッケージのインストールは不要です。

Xcode 26以降、macOS 15以降に対応しています。

```text
Zime/                    ← GitHub直下・開発時に選択するフォルダ
├── Zime.xcodeproj/       ← Xcodeプロジェクト
├── Zime/                ← SwiftUIソース・アセット
├── Tests/               ← タイマーの動作テスト
├── scripts/             ← ビルド・テスト用スクリプト
└── README.md
```

## 使い方

- 再生アイコンで開始、同じボタンで一時停止・再開します。
- 左の矢印で現在の時間をリセット、右の矢印で次の勉強・休憩へ進みます。
- 右上の設定アイコン、または **⌘,** で設定を開きます。
- 勉強時間（1〜180分）・休憩時間（1〜60分）、共通の色を設定できます。
- 開始すると約1.2秒かけて上から反時計回りに色が満ち、その後に勉強時間の計測を始めます。
- 勉強中は時計回りに色が減り、空になると休憩に切り替わり、反時計回りに色が満ちます。休憩後は満ちた状態から次の勉強に入ります。
- ウィンドウは小（200×240）・中（260×300）・大（320×360）、幅・高さの指定、端のドラッグでサイズ変更できます。数値はコンテンツ領域のサイズです。
- 自動切替、終了音、最前面表示を切り替えられます。
- 設定は端末内に保存します。計測途中の時間変更は次の回から反映します。

スペースで開始・一時停止、**⌘R** でリセット、**⌘→** で次の時間へ進みます。
スリープ中も経過時間に含めます。復帰すると実際の経過時間に追いつきます。

## コマンドで確認

```sh
bash scripts/build.sh
bash scripts/test.sh
open build/Build/Products/Debug/Zime.app
```

`build/` にローカルビルドを出力します。配布用の署名・公証は別途必要です。

アイコンは `Zime/Assets.xcassets/AppIcon.appiconset/` に全サイズを保存しています。`swift scripts/generate-icon.swift` で再生成できます。

[minee 4](https://mineetimer.com/ja/products/minee-4) の「数字に頼らず時間を感じる」仕組みを参考にした独立アプリです。製品とのBluetooth連携はありません。
